# Emoji Snake Zonewars / 表情蛇 · 区域事件乱斗

Emoji Snake - Zone Events（单人，常驻 AI）。一个基于 Canvas 的贪吃蛇小游戏，加入表情区域事件、技能槽、连击倍率与动态对手，让节奏更紧凑、更“乱斗”。

## 特色
- **表情区域事件**：五种区域改变速度与掉落规则，并触发弹幕/特殊事件。
- **技能槽**：拾取 🎁 获得一次性技能，支持护体、冲刺、吸附、炸裂。
- **常驻 AI 对手**：多人格 AI 持续刷新，分数越高，对手越多。
- **连击与情绪倍率**：连续拾取触发情绪表情，连击越高加成越强。
- **无外部素材依赖**：音效与 BGM 由 Web Audio 生成。
- **桌面 + 移动端**：键盘与触屏控制都可玩。

## 玩法概览
### 区域事件
- 😂 **哈哈区**：喷 😂 弹幕，命中后短暂强制摆头。
- 😢 **呜呜区**：掉 💧 泪滴，拾取获得短护盾。
- ❓ **??? 区**：掉 🎲 奇遇，随机补技能并小幅扰动方向。
- 😡 **暴走区**：掉 💢 火花，短冲刺但可能随机丢技能。
- 😴 **犯困区**：掉 💤 睡泡，肉链更耐久（全场保鲜）。

### 技能
- 🛡️ **护体**：短时间免疫撞击伤害。
- 🏃 **冲鸭**：长按消耗体力冲刺（体力槽）。
- 🧲 **吸吸**：吸附附近掉落与彩蛋。
- 💣 **炸裂**：爆炸波及范围内目标并削减长度。

## 操作说明
### 键盘
| 操作 | 按键 |
| --- | --- |
| 移动 | W / A / S / D 或方向键 |
| 加速（消耗长度） | E |
| 使用技能 | 1 / 2 / 3（长按预览，松手释放） |
| 丢弃技能 | Z / X / C 或 Shift + 1 / 2 / 3 |
| 暂停 | Space |
| 切换模式 | M（穿墙 / 撞墙） |
| 重开 | R |
| 静音 | V |

### 移动端
- 左侧虚拟摇杆移动
- 右侧按钮：加速 / 技能 / 暂停

## 快速开始
### 环境要求
- Node.js（建议使用 LTS）

### 安装与运行
```bash
npm install
npm run dev
```
浏览器访问：`http://localhost:3000`

> 也可以使用 `npm start` 启动，同样会运行 `server.js`。

## 技术栈
- Vanilla JavaScript + Canvas
- Web Audio API
- Express（静态资源服务）

## 项目结构
- `server.js`：Express 静态服务入口
- `public/index.html`：页面结构与 UI
- `public/style.css`：样式
- `public/game.js`：核心玩法逻辑（蛇、AI、区域事件、技能、音效）

## 数据存储
游戏数据保存在浏览器本地存储（localStorage）：
- 最高分
- 收集册进度
- 音效开关
